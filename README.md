# 포스트하네스 — 오늘의 AI를 넘어서

포스트하네스(POSTHARNESS)는 AI 뉴스와 기술의 흐름을 전하는 사이트입니다. 새로운 모델과 서비스, 기업·산업의 변화를 다루고, AI를 이해하고 활용하는 데 필요한 가이드를 제공합니다.

**[포스트하네스 홈](https://postharness.com/)**

## AI 용어사전

AI 용어사전은 포스트하네스의 AI 가이드 안에 있는 개념 설명 모음입니다. 기사나 서비스를 이용하다 만나는 용어의 뜻과 작동 원리를 예시와 함께 살펴볼 수 있습니다. 아래 링크에서 각 용어의 상세 설명을 읽으실 수 있습니다.

**[AI 용어사전 전체 보기](https://postharness.com/guide/glossary/)**

### 모델과 작동 원리

- **[토큰 (Token)](https://postharness.com/guide/glossary/token/)** — AI가 글을 처리하는 단위와 토큰 사용량·비용의 관계를 살펴봅니다.
- **[파운데이션 모델 (Foundation Model)](https://postharness.com/guide/glossary/foundation-model/)** — 여러 AI 작업의 바탕이 되는 모델의 특징과 LLM·베이스 모델과의 차이를 알아봅니다.

### 학습과 추론

- **[사전학습 (Pretraining)](https://postharness.com/guide/glossary/pretraining/)** — 언어 모델이 다음 토큰을 예측하며 기본 능력을 학습하는 과정을 살펴봅니다.
- **[사후학습 (Post-training)](https://postharness.com/guide/glossary/post-training/)** — 사전학습한 모델을 지시 수행과 추론에 맞게 다듬는 방법을 알아봅니다.

### 지시와 참고 자료

- **[컨텍스트 (Context)](https://postharness.com/guide/glossary/context/)** — 질문·대화·참고 자료가 답변에 미치는 영향과 컨텍스트 윈도우의 한도를 살펴봅니다.
- **[프롬프트 (Prompt)](https://postharness.com/guide/glossary/prompt/)** — AI에 전달하는 입력의 역할을 구체적인 예시와 함께 알아봅니다.

### 에이전트와 개발

- **[에이전트 (AI Agent)](https://postharness.com/guide/glossary/agent/)** — 목표에 따라 도구를 선택하고 작업을 수행하는 방식, 챗봇·워크플로와의 차이를 살펴봅니다.
